# 신규 브랜드 상담 → 제안서 초안 도우미 (시제품)

화장품 OEM/ODM 회사의 국내 · 해외 영업을 돕는 시제품입니다.
브랜드 담당자가 원하는 제품을 적으면, 빠진 정보를 한 번 되묻고, 기본 처방 후보 · 예상 일정 · 나라별 확인 항목을 정리합니다.
가격 · 처방 · 납기는 영업 담당자가 확정합니다.

> 모든 데이터는 가상입니다. AI 부분은 규칙으로 흉내 낸 모의 AI입니다.

## 실행

- 시연: (공개 후 링크)
- 로컬: `python -m http.server -d site 8080` → http://localhost:8080
- 시험: `node --test tests/` · 채점: `node eval/run.mjs`
