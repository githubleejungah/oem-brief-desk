# ADR 0001 — 정적 페이지와 규칙 기반 모의 AI

- 상태: 제안 · 2026-11-24
- 근거: requirements Q2 · Q8 · Q12

## 결정

GitHub Pages 정적 페이지로 만들고, AI 제안은 규칙 기반 모의 엔진으로 만든다. 상담은 보는 사람 브라우저(localStorage)에만 둔다.

## 이유

- 지원 마감이 2026-11-25라 하루 안에 안정적으로 끝내야 한다.
- 심사자가 링크를 열 때마다 같은 결과가 나와야 한다.
- API 키 노출 · 요금 · 개인정보 전송 위험이 없다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 실제 LLM API + 작은 서버 | 키 관리 · 요금 · 하루 안 안정화 어려움 |
| 생성형 AI 대화창 시연 영상 | 처방 목록 · 출처 · 영업 확정 흐름을 보여 줄 수 없음 |

## 결과

- 점수는 가상 데이터에 맞춘 규칙의 점수라 실제 성능이 아니다(가정 AS-3). 문서와 화면에 그렇게 적는다.
- 입사 후에는 `engine.suggest()`만 회사 서버 AI 호출로 바꾸도록 입력 · 출력 모양을 고정한다.
